# Web Application Development 1 Project

A full-stack web application developed as part of my Web Application Development 1 module at South East Technological University (SETU).

The project demonstrates the development of a dynamic web application using JavaScript, Node.js and Express, following the MVC (Model-View-Controller) design pattern.

## Live Application

The application is deployed on Render:

https://wa1-ca1-bo.onrender.com/

## Features

- Add, update and delete records
- Dynamic views
- Search and sorting functionality
- Application statistics
- User account management and sessions
- Image upload and display
- Custom helpers
- MVC architecture

## Technologies Used

- JavaScript
- Node.js
- Express.js
- JSON
- Handlebars
- HTML
- CSS
- MVC architecture
- Git and GitHub
- Render

## What I Learned

This project allowed me to develop my understanding of:

- JavaScript variables, functions, arrays and objects
- Building web applications with Node.js and Express
- Routes and controllers
- Models and dynamic views
- CRUD functionality
- Search and sorting
- User sessions
- Image handling
- Structuring an application using MVC

## Academic Context

This project was developed as the final project assignment for the Web Application Development 1 module at SETU.
